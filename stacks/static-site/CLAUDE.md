# <Site>

Plain HTML, CSS and JS on GitHub Pages. No build step, no framework.

## Every change

`npm run check` runs html-validate, prettier --check and Lighthouse CI. CI runs the same command.

## Review

`/review` runs the **Standards** axis only on this repo. There is no `/tdd` and no KB.

## UI

New pages start as a Claude Design mock. Once the look is approved, build it in plain HTML and CSS.
