# <Project> knowledge base

OKF v0.2 bundle. Format: the `domain-modeling` skill's KB-FORMAT.md in agent-workflow.

Glossary: [glossary.md](glossary.md)

## Types

Approve or edit these with the project's first grilling session.

| Type | Meaning | When to use |
|---|---|---|
| decision | A choice made against real alternatives | Hard to reverse, surprising without context, a real trade-off |
| gotcha | Behaviour that bites if you don't know it | A bug or near-miss someone would otherwise repeat |
| domain | A business rule or fact about the problem space | The code depends on it but can't explain it |
| runbook | Steps to operate or recover something | A task done rarely enough to forget |
